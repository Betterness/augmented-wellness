# Episode 003 — Dr. Lloyd Camper: Healthspan AI Interviewer

This is the public artifact for Augmented Wellness episode 003 with Dr. Lloyd Camper.

The episode's central idea is that longevity starts with knowing your baseline. Exercise, blood work, body composition, VO2 max, recovery, and medical context become more useful when they are read together instead of treated as isolated scores.

The artifact turns that idea into something practical: a private AI interviewer that helps a person organize goals, history, reports, habits, missing data, and clinician questions before a visit.

## What is included

- `context-portfolio/` — the main artifact: a Healthspan AI Interviewer and Context Portfolio.
- `context-portfolio/interviewer-agent.md` — copy this into Claude, ChatGPT, Codex, a local agent, or any LLM to interview yourself.
- `context-portfolio/01-healthspan-identity.md` through `06-betterness-connection.md` — modular files for identity, goals, risks, reports, labs, habits, recovery, and the Betterness connection.
- `artifact.md` — the landing page for the portfolio artifact and Betterness connection.
- `prompts.md` — prompts for using an assistant to organize questions and prepare for a medical conversation.
- `claims.md` — public claim guardrails for the episode.

## How to use this

Start with `context-portfolio/interviewer-agent.md`. Paste it into Claude, ChatGPT, Codex, a local agent, or another LLM and let it interview you. Then save the answers into the markdown files in `context-portfolio/`.

Once the portfolio exists, you can use it three ways:

1. **LLM context** — Add the markdown files to a project or prompt so every conversation starts with your healthspan goals, reports, constraints, and questions.
2. **MCP resource** — Serve the folder as an MCP resource so connected tools can read it automatically.
3. **Betterness connection** — Go to [betterness.ai](https://betterness.ai), connect your account, and let Bett-i enrich the portfolio with permissioned labs, reports, wearables, goals, and lifestyle context.

The goal is not to diagnose yourself from a dashboard. The goal is to understand what information is missing, what should be interpreted by a qualified clinician, and what habits are realistic enough to continue for years.

## Guardrails

This artifact is educational. It is not medical advice, diagnosis, treatment, or a replacement for a physician. Do not use AI, wearable data, labs, DEXA, VO2 max, regenerative medicine information, or this repository to make medical decisions without a qualified clinician.

## Source posture

This artifact is based on the episode conversation and public, general medical-literacy framing. It deliberately does not publish Demian's private medical reports. The episode discusses those reports live as an example of how a clinician and a personal agent can make health data easier to understand.
